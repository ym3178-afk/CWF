Letters
Across
the Sea

A computational installation about family memory, paper, wind, flowers, distance, and return. This folder contains one static 2D canvas and two dynamic 2D canvases.

2D Canvas 01 · Static

The Letter Archive

A quiet archive board: old paper, Thailand map, family photo, red thread, tickets, and memory labels.

2D Canvas 02 · Dynamic

Wishing Tree

Red flowers bloom on a tree. Hanging letters swing with wind. Move the mouse to change the wind.

2D Canvas 03 · Dynamic

Red Cotton Flower

A large red flower carries floating letter papers against a muted teal paper background.

2D Design Statement

These p5.js canvases turn memory into layered images. Paper becomes an archive, a wishing tree, and a blooming cotton flower. Static composition, wind, growth, and suspended letters translate family memory into quiet visual movement.

Some letters crossed the sea.
Some never arrived.
